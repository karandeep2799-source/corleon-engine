# SEO and AEO Best Practices

- Write a unique, accurate title and description for each indexable page.
- Keep canonical URLs, robots directives, sitemap entries, and hreflang values consistent.
- Use structured data only when it accurately describes visible page content and follows the relevant schema vocabulary.
- Do not add review scores, prices, availability, author credentials, or other facts that cannot be verified.
- Make content useful to readers first: answer the query, explain the evidence, and identify the author or source where relevant.
- Optimize for answer engines through clear definitions, descriptive headings, concise answers, and traceable sources, not keyword stuffing.
- Apply EEAT principles by making experience, expertise, authoritativeness, and trustworthiness visible where supported.
- Validate metadata and structured data against the actual page and content model before proposing changes.
