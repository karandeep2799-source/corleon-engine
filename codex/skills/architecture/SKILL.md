# Corleon Architecture Skill

Inspect before changing. Map application boundaries, authentication, authorization, database dependencies, external integrations, queues/webhooks, observability, and deployment topology.

Workflow:
1. Inspect repository.
2. Identify constraints and existing conventions.
3. Produce a plan.
4. Implement the smallest safe change.
5. Test and review.
6. Require approval for production-impacting operations.
